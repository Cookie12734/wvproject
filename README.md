# VALORANT募集掲示板

VALORANTのプレイヤー同士が、安心して一緒に遊ぶ相手を探せる募集掲示板アプリケーションです。

XなどのSNSでも募集はできますが、相手がどのような人なのか分かりづらく、不安を感じることがあります。  
そこで、ユーザー評価・コメント・通報・ブロック機能などを用意し、募集相手の情報を確認しながら利用できる掲示板を作成しました。

## 工夫した点

### 安心して募集できる仕組み

単に募集を投稿できるだけではなく、ユーザー評価、コメント、通報、ブロック機能を実装しました。
これにより、募集相手の情報を確認したり、問題のあるユーザーへの対策を行えるようにしています。

### Good率によるユーザー評価

ユーザーに対して Good / Bad の評価を付けられるようにし、評価割合を表示できるようにしました。
募集一覧では評価数順やGood率順で並び替えられるため、信頼できそうなユーザーを見つけやすくしています。

### 管理者向けの通報管理

通報された募集、コメント、ユーザーを管理者が確認できるようにしました。
通報は未対応 / 対応済みで管理でき、必要に応じてユーザーの書き込み禁止やBANを行えます。

### チャットとブロック機能

ユーザー同士で直接やり取りできるチャット機能を実装しました。
また、トラブル防止のため、ブロック機能を用意し、ブロック関係にあるユーザーとはチャットできないようにしています。

### メール機能

パスワードリセットやメールアドレス変更など、実際にメールを利用する機能を実装しました。
本番環境ではSMTPを使用し、開発環境ではコンソール出力に切り替えられるようにしています。

## 開発目的

このアプリケーションは、Djangoを用いたWebアプリケーション開発の学習と、実際に利用できる掲示板サービスの作成を目的として開発しました。

ユーザー登録、ログイン、CRUD処理、評価、通報、チャット、通知、管理者機能など、Webアプリケーションに必要な基本機能を一通り実装しています。
